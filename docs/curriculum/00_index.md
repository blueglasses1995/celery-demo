# Celery学習カリキュラム

このカリキュラムは、Celeryを基礎から実践的に学ぶための体系的な学習パスです。

## カリキュラムの構成

   - 非同期タスクキューの概念
   - Celeryのユースケース
   - アーキテクチャの概要

2. **[環境構築](./01_basics/02_environment_setup.md)**

   - Celeryのインストール
   - メッセージブローカー（Redis/RabbitMQ）のセットアップ
   - 開発環境の確認

3. **[最初のタスク](./01_basics/03_first_task.md)**
   - Hello Worldタスク
   - タスクの定義
   - ワーカーの起動
   - タスクの実行

4. **[タスクの基本](./01_basics/04_task_basics.md)**
   - タスクデコレータの理解
   - タスクへの引数渡し
   - タスクの戻り値
   - タスクの命名規則

## 学習の進め方

### 推奨学習パス

1. **初級者向け（Celery初心者）**
   - レベル1: 基礎編を順番に学習
   - レベル2: 実践編の前半（5-8）を学習
   - 簡単なプロジェクトで実践

2. **中級者向け（Pythonの経験あり）**
   - レベル1: 基礎編を流し読み
   - レベル2: 実践編を深く学習
   - レベル3: 応用編の必要な部分を学習
   - プロジェクト1-2で実践

3. **上級者向け（非同期処理の経験あり）**
   - レベル1-2: 復習として確認
   - レベル3: 応用編を重点的に学習
   - レベル4: 運用編を深く学習
   - すべてのプロジェクトで実践

### 学習のヒント

- **ハンズオン重視**: 各セクションのコード例は必ず自分で実行する
- **小さく始める**: 複雑な機能は後回しにし、基本から確実に
- **実践で学ぶ**: 簡単でも良いので、自分のプロジェクトで使ってみる
- **ドキュメントを読む**: [公式ドキュメント](https://docs.celeryproject.org/)も併せて参照
- **コミュニティを活用**: Stack OverflowやGitHubで質問・情報収集

## 前提知識

このカリキュラムを始める前に、以下の知識があると望ましいです:

- **必須**
  - Python 3.7以上の基本文法
  - 関数とデコレータの理解
  - モジュールとパッケージの概念

- **推奨**
  - 基本的なコマンドライン操作
  - 仮想環境（venv、virtualenv）の使い方
  - 基本的なネットワークの知識

- **あると良い**
  - Web開発の経験（Django、Flask等）
  - Redisやデータベースの基礎知識
  - Dockerの基本的な使い方
