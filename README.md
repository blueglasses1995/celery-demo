## 🎯 学習の進め方

### 初級者向け（Celery初心者）
1. レベル1: 基礎編を順番に学習
2. レベル2: 実践編の前半（5-8）を学習
3. 簡単なプロジェクトで実践

### 中級者向け（Pythonの経験あり）
1. レベル1: 基礎編を流し読み
2. レベル2: 実践編を深く学習
3. レベル3: 応用編の必要な部分を学習
4. プロジェクト1-2で実践

### 上級者向け（非同期処理の経験あり）
1. レベル1-2: 復習として確認
2. レベル3: 応用編を重点的に学習
3. レベル4: 運用編を深く学習
4. すべてのプロジェクトで実践

## 📖 スタートガイド
